Stop destructive shell commands before they run. 壊すコマンドを、
実行する前に止める。

command-guardian reads a Bash command, works out what it would delete, truncate or format, and answers allow, ask or block. Use it from the CLI or as a pre-execution hook for AI coding agents. command-guardian は Bash コマンドを読み、何を削除・切り詰め・フォーマットするのかを取り出して、allow・ask・block を返します。CLI からも、AI コーディングエージェントの実行前フックからも使えます。 

$ mise use -g github:ba0918/command-guardian

allow

The targets are temporary, explicitly allowed, or committed in Git with no changes. Exit code 0.

対象が一時領域、許可したディレクトリ、または変更のない Git 管理下にあるとき。終了コード 0。

ask

The checker cannot tell whether the loss is recoverable, such as uncommitted work. Review before running. Exit code 1.

未コミットの変更など、失っても戻せるか判断できないとき。実行前に確認してください。終了コード 1。

block

System directories, .git, your home, or a path whose value cannot be resolved. Exit code 2.

システム領域、.git、ホーム、値を解決できないパスなどが対象のとき。終了コード 2。

Install導入

Install the Linux x86_64 binary from GitHub Releases with mise: mise で GitHub Releases から Linux x86_64 用の実行ファイルを導入します。 

$ mise use -g github:ba0918/command-guardian
$ command-guardian --help

Or build from source with a recent stable Rust toolchain: 最新の安定版 Rust があれば、ソースからもビルドできます。 

$ git clone {{repo_url}}.git
$ cd command-guardian
$ cargo install --path . --locked

Check a commandコマンドを判定する

Pass the whole command as one single-quoted argument so your shell does not expand it first. シェルに先に展開されないよう、コマンド全体をシングルクォートで1つの引数として渡します。 

$ command-guardian check 'rm -rf /etc/nginx' --cwd /tmp
$ command-guardian check 'rm -rf /etc/nginx' --format json

Configure it per projectプロジェクトごとに設定する

Settings layer built-in defaults, your user configuration, and the nearest .command-guardian.toml. Project configuration can only make protection stricter unless you list the project in trusted_projects. 既定値、利用者の設定、最寄りの .command-guardian.toml の順に重ねます。trusted_projects に載せない限り、プロジェクトの設定は保護を強める方向にしか働きません。 

# .command-guardian.toml
[paths]
protected_roots = ["data"]

[[commands.guard]]
program = "git"
reason = "Review the destination and commits before pushing."
verdict = "ask"
deny = [["push"]]
