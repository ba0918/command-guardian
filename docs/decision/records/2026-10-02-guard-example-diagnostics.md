# 診断付き設定例の受理条件

## Context

解析に失敗しても回復した起動が一件なら、設定例が一致として受理されていた。
例の完全な解析を要求するかは既存仕様で明示されていなかった。
本体と内側の解析診断をともに確認し、不完全な例による規則の有効化を防ぐ。

## Agreements

- A1 設定例の意味解析に診断がある場合は、その規則だけを無効化して警告する。トップレベルと内側の解析の両方を対象とし、正常な例の一致判定と他の規則は維持する。
  - why: 回復した一部分が一致するだけでは、利用者が書いた例全体の正しさを確認できない。[REQ-034](../../ir/guards.md#REQ-034)の例の受理条件を明示する。
  - decided_by: 利用者が推奨案を選択
