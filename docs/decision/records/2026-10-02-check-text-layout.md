# check の通常出力の行数

## Context

非 allow の説明は最大4行だが、check が判定の行を別に足して5行になっていた。
必要な操作・対象・理由・代替・追加所見を削らず、通常出力全体を4行以内に収める。
JSONとhookが使う説明は配置変更の対象にしない。

## Agreements

- A1 check の非 allow の通常出力は、判定と説明の最初の行を同じ行にまとめ、全体を2行から4行にする。JSONの説明とhookの拒否理由は変更しない。
  - why: 判定の行を別に加えると、[REQ-011](../../ir/messages.md#REQ-011)の行数を超える。情報の削除ではなく表示配置の変更で解消する。
  - decided_by: 利用者が推奨案を選択
